## Contradictions, lacunes et tests ciblés Status

- **« Aucun serveur ne voit de métadonnées » contre la déclaration d’infrastructure.** Le blog dit qu’aucun nœud ne voit les métadonnées de conversation; la page Status d’octobre 2026 déclare IP + content-topic visibles par Store/Filter/LightPush et 15 jours de logs IP pour certains nœuds. Peut-être des couches/identifiants différents, mais la formulation absolue n’est pas soutenue. [Infrastructure](https://status.app/help/getting-started/privacy-with-status-infrastructure-and-insights), [architecture marketing](https://status.app/blog/building-the-web3-anonymous-chat-stack-how-peer-to-peer-protocols-replace-servers).
- **Crypto variable selon les sources.** Les anciens billets décrivent X3DH + Double Ratchet; la spec 1:1 de 2026 permet X3DH ou Noise; Communities décrit un ratchet de groupe. Il faut associer le code exact aux versions 2.39 avant d’affirmer une suite et des garanties uniformes.
- **Wallet key/chat key.** Le guide des clés emploie une formulation où la clé publique identifie profil et wallet, puis précise que chat key et adresse wallet sont des keypairs dérivées distinctes. Séparation/linkage à confirmer dans code et build.
- **Community History.** Guide CHS dit BitTorrent activé par défaut et expose l’IP aux membres; 2.39 ajoute Logos Storage mais laisse le choix Torrent/Storage/désactivé. Le défaut effectif et la migration des communautés sont à tester.
- **Version/audit.** Billet 2.39 daté 8 oct. tandis que release GitHub consultée affiche RC.7 et 2.38.2. Audit public de l’app remonte essentiellement à 2019; finding-level du rapport ToB non disponible.
- **Forensics/légal/OSINT.** Pas de manifeste app décompilé, DNS/ASN passif, label store, rapport public de demandes, cas de disclosure Status, ou test d’acquisition forensique contrôlé dans cette étape.
- **Tests pour fermer ces inconnues.** Reproduire un build 2.39 par OS; mapper commit Logos Delivery et dépendances; capturer flux IP/topic, APNs, backup/sync, CHS Torrent vs Logos Storage avec comptes contrôlés; lire labels stores, manifests, entitlements, SDK et permissions de la version exacte; tester acquisition verrouillée/déverrouillée avec OS+patch+outil+app notés; récupérer les rapports Deja Vu/ToB ou obtenir confirmation d’indisponibilité.
