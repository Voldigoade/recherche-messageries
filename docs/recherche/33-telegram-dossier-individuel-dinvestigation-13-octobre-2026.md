# Telegram — dossier individuel d’investigation (13 octobre 2026)

!!! note "Registre de preuves — Phase 2"
    Ce dossier est une pièce de recherche datée. La [conclusion canonique](../resume.md) est celle du rapport final 1.0. Les synthèses antérieures et renvois à la Phase 3 restent historiques. `UNKNOWN` reste `UNKNOWN`.

**Périmètre.** Telegram est un service cloud centralisé. Sauf indication explicite, « Telegram » ci-dessous signifie Cloud Chats/Groups, et non Secret Chats. Les bots, canaux, mini-apps, Premium et appels ont des frontières et tiers supplémentaires.

## Telegram — audits, repositories, mobile, forensics et droit

- **Repository/builds:** official Android client [`TelegramOrg/Telegram-Android`](https://github.com/DrKLO/Telegram) and iOS [`TelegramMessenger/Telegram-iOS`](https://github.com/TelegramMessenger/Telegram-iOS) (fork/repository ownership differs by client); [reproducible-build guide](https://core.telegram.org/reproducible-builds) says supported from 5.13 and experimental. It prescribes exact release tag/build matching and APK/IPA comparison. No current build was rebuilt here. GitHub source is not a server audit: the official FAQ explicitly says published server code cannot prove what is running.
- **Activity/dependencies/CI:** repository activity, signed tag reach, current dependency inventory and active maintainer count have not been normalized across Android/iOS/web/desktop in this turn; mark unresolved rather than inferring from stars or commits. Client OSS does not cover Bot API backend, cloud server, moderation or hosted file storage.
- **Mobile:** [Google Play listing](https://play.google.com/store/apps/details?id=org.telegram.messenger) and [Apple listing](https://apps.apple.com/us/app/telegram-messenger/id686449807) expose developer-provided Data Safety / App Privacy disclosures. Those are declaration surfaces; the actual manifests, APK SDK list, runtime analytics/crash traffic, FCM/APNs payload, permissions and contact upload were not independently inspected in this phase. Official FAQ says camera is requested upon user actions and describes source-based check, but that remains vendor explanation until build-specific analysis. No assertion here that Firebase/analytics is absent.
- **Forensics:** a 2025 peer-reviewed DFRWS/FSI paper now documents Cellebrite UFED Touch full-file-system extraction of Telegram iOS **11.1.1** data on iPhone SE/iPhone 7 test devices, followed by decoding of `db_sqlite`, WAL and media. It does **not** report the iOS version, exact UFED build or lock state; it does not demonstrate an unlock bypass, current-build extraction or recovery of deleted data. This replaces the earlier blanket “no versioned tool result found” wording only for this dated test. [PDF](https://dfrws.org/wp-content/uploads/2025/03/Forensic-analysis-of-Telegram-Messeng_2025_Forensic-Science-International-D.pdf). Cloud chat also differs: data may be obtainable via Telegram/backend process rather than device bypass.
- **Law-enforcement evidence ladder:** (i) **technically available**: server-controlled Cloud Chat data, subscriber account and metadata; (ii) **officially declared**: privacy policy allows phone/IP disclosure upon valid order in a qualifying criminal case; privacy policy says metadata may be retained up to 12 months if collected; (iii) **actually documented**: in the 2022 Indian civil copyright case, Telegram filed account-identification data under seal and the Court reviewed a chart listing administrator names, phone numbers and IP addresses for some channels; plaintiffs later said only names/IPs were supplied and some information was unavailable. The record permits disclosure to police but does not establish a police transfer. A 2025 U.S. affidavit says Telegram began responding around Sep 2024 with subscriber details, typically phone number and last-login IP, but this is an agent’s description of current practice, not proof of the exact return in that case. 2024 aggregate transparency counts (900 U.S. cases / 2,253 users) were publicly reported from bot output, not itemized returns. No verified case here establishes that Telegram delivered ordinary Cloud Chat plaintext in a criminal matter. [Delhi HC order 24 Nov. 2022](https://indiankanoon.org/doc/119238688/), [follow-up 1 Dec. 2023](https://indiankanoon.org/doc/2402568/), [DOJ affidavit, filed 31 Jul. 2025](https://www.justice.gov/usao-ndil/media/1409806/dl?inline=).
- **Sources:** [Telegram FAQ](https://telegram.org/faq?setln=en), [privacy](https://telegram.org/privacy), [MTProto](https://core.telegram.org/mtproto), [reproducible builds](https://core.telegram.org/reproducible-builds), [NDSS contact discovery](https://www.ndss-symposium.org/ndss-paper/all-the-numbers-are-us-large-scale-abuse-of-contact-discovery-in-mobile-messengers/), [Delhi High Court order, 30 Aug. 2022](https://dhccaseinfo.nic.in/jupload/dhc/PMS/judgement/31-08-2022/PMS30082022SC2822020_121640.pdf), [Delhi High Court compliance order, 24 Nov. 2022](https://indiankanoon.org/doc/119238688/), [follow-up order, 1 Dec. 2023](https://indiankanoon.org/doc/2402568/), [US DOJ affidavit](https://www.justice.gov/usao-ndil/media/1409806/dl?inline=), [official transparency bot](https://t.me/transparency), [DOJ/US court case archive, Telegram seizure warrant 2026](https://www.justice.gov/usao-dc/media/1437596/dl?inline=).
