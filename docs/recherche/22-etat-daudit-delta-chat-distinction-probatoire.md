# État d’audit Delta Chat — distinction probatoire

!!! note "Registre de preuves — Phase 2"
    Ce dossier est une pièce de recherche datée. La [conclusion canonique](../resume.md) est celle du rapport final 1.0. Les synthèses antérieures et renvois à la Phase 3 restent historiques. `UNKNOWN` reste `UNKNOWN`.

La documentation fournisseur répertorie les audits et confirme plusieurs correctifs; cela établit un **Vendor Claim** appuyé par historique public de releases, pas le fait qu’un tiers ait retesté chaque fix sur chaque plateforme. Pour les audits 2019/2020/2023 examinés ici, aucune durée exacte de retest ni aucun rapport de retest indépendant n’a été trouvé. L’analyse ETH 2024 constitue une vérification séparée : les chercheurs ont relu les patchs SecureJoin et ont écrit ne pas avoir trouvé de défaut dans ces patchs; ceci ne reteste pas tous les findings des audits précédents.
