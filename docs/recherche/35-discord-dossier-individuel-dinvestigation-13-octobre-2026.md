# Discord — dossier individuel d’investigation (13 octobre 2026)

!!! note "Registre de preuves — Phase 2"
    Ce dossier est une pièce de recherche datée. La [conclusion canonique](../resume.md) est celle du rapport final 1.0. Les synthèses antérieures et renvois à la Phase 3 restent historiques. `UNKNOWN` reste `UNKNOWN`.

**Périmètre.** Discord messages/text, server channels and DMs are not E2EE. As of March 2026 DAVE E2EE is on by default for eligible voice/video calls, excluding Stage channels. A/V keying and message-store semantics are distinct.

The library’s public commit/release and GitHub advisory are directly traceable, but we did not extract per-platform dependency lockfiles, CI signing, current client commit, exact maintainer count or reproducible app build. Do not report “the Discord app is open source” or “Discord binaries reproduce” from DAVE openness.

**Mobile privacy:** [Apple listing](https://apps.apple.com/gb/app/discord-talk-play-hang-out/id985746746), [Google Play listing](https://play.google.com/store/apps/details?id=com.discord) and [Discord policy](https://discord.com/privacy) are disclosure surfaces. Android manifests/iOS entitlements, camera/microphone/photos/contacts/location permission requests, FCM/APNs payloads, Firebase/Sentry/analytics SDKs and runtime network behavior were not captured. No absence/presence claim about a named SDK is made here.

**Infrastructure & forensics:** The 2026 Cloudflare migration is primary evidence only for voice/video. DNS/ASN/CDN of Discord API/text/file endpoints has not been passively sampled. No public case was found in this evidence pass mapping **Cellebrite/GrayKey/Magnet version + platform OS + Discord build + acquisition date**. The Bryant case is provider-side disclosure, not a phone-extraction demonstration. Locally cached decrypted messages and push/notification artifacts need app-build- and OS-specific testing.

**Law enforcement:** distinguish (i) technically stored/readable text DMs and group/server content, (ii) official LE guide/transparency declarations, and (iii) demonstrated delivery: in *U.S. v Bryant* the FBI received many DMs from Discord after a warrant although they were no longer stored on the user’s phone. The affidavit also says Discord voluntarily shared account/communications information with RCMP shortly after the incident. This is direct evidence of actual provider disclosure of plaintext chat records, not merely theoretical availability. [DOJ complaint, 2:26-mj-00618-BAT](https://www.justice.gov/usao-wdwa/media/1464546/dl), [Discord law enforcement guide](https://discord.com/safety/360044157931-working-with-law-enforcement), [transparency hub](https://discord.com/safety-transparency), [DAVE protocol](https://daveprotocol.com/), [Cloudflare edge engineering post](https://discord.com/blog/how-we-moved-discord-voice-to-the-edge).

Le cas Boystown indique des données effectivement obtenues du réseau/FAI pour le Ricochet historique; il ne prouve ni remise du contenu ni défaillance de Refresh 3.0.46. L’audit NCC historique est cité dans le dossier avec sa véritable portée; il n’a pas audité Refresh/Tor v3.
