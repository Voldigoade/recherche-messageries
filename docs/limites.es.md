# Limitaciones

<p>Media para propiedades bien documentadas; menor para metadatos de producción y versiones no probadas.</p><ul><li>Dispositivo comprometido / desbloqueado y spyware.</li><li>Copias, capturas o divulgación por el contacto.</li><li>Rastros iniciales de Discord, alias, avatar, voz o archivos reutilizados.</li><li>Correlación global; datos de relés, ISP, operador, tiendas y copias según la ruta.</li></ul><p>Entre las incógnitas importantes están correcciones y retests de Session, payloads push móviles exactos, logs de relés, PFS y retests del escritorio Threema, binarios actuales y resultados forenses con dispositivo, sistema, app y bloqueo precisos. Una extracción histórica no se presupone efectiva tras una corrección documentada.</p><a class="fact-source" href="https://github.com/Voldigoade/recherche-messageries/blob/main/research/rapport-final-messageries.md#L397" aria-label="Fuente:  — report.limits">[1]</a><p>Las pruebas detalladas se conservan en el <a href="/recherche-messageries/limites/">registro Fase 2 en francés</a>. La traducción es una reformulación, no evidencia nueva.</p>
