# OPSEC

<p>Proteja dispositivos, identidades y archivos antes de cambiar de mensajería. Use sistemas y apps actualizados, bloqueo robusto, copias controladas, vistas previas ocultas y solo sus dispositivos vinculados. Un mensaje temporal no impide que el destinatario lo copie.</p><p>No reutilice alias, avatares, firmas ni cuentas cloud. Inspeccione metadatos de fotos/documentos, autores, nombres y miniaturas. Considere voz, lenguaje y horarios. VPN/Tor desplazan un observador; compruebe la ruta real.</p>
