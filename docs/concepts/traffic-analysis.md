# Analyse de trafic

## Définition courte

Déduire des informations à partir des horaires, tailles, volumes et chemins, sans lire le texte.


## Exemple concret

Deux connexions répétées apparaissent à quelques secondes d’écart : un observateur cherche une corrélation.


## Ce que cela protège

Padding, délais ou trafic de couverture peuvent limiter certaines inférences selon leur conception.


## Ce que cela ne protège pas

Le chiffrement seul ne masque pas tous ces indices.


## Pourquoi cela compte

Une architecture onion à faible latence ne prouve pas l’immunité globale.
