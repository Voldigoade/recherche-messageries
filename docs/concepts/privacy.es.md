# Privacidad y minimización de datos

## Definición breve

Reducir la información sobre usted que puede observarse, conservarse o vincularse.


## Ejemplo concreto

El mensaje sigue secreto, pero el servicio conoce el número y la última conexión.


## Qué protege

Reduce datos de contenido o contexto según arquitectura y ajustes.


## Qué no protege

No significa automáticamente anonimato ni ausencia total de metadatos.


## Por qué importa

La información útil para una investigación no se limita a mensajes.
