# Modèle de menace

## Définition courte

Préciser ce que vous protégez, contre qui, et avec quelles contraintes.


## Exemple concret

Alice veut cacher son numéro à Bob ; une autre personne veut éviter un numéro même chez le service. Les choix diffèrent.


## Ce que cela protège

Rend les comparaisons et conditions de configuration utiles.


## Ce que cela ne protège pas

Ce n’est ni une garantie, ni une note globale qui remplace les inconnues.


## Pourquoi cela compte

Deux utilisateurs peuvent avoir deux bons choix sans contradiction.
