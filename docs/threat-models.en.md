# Threat models

<p>Specify what you protect, from whom, and under which constraints.</p><ol><li>TM1 — Curious provider</li><li>TM2 — Compromised infrastructure</li><li>TM3 — Malicious operator</li><li>TM4 — ISP / Wi-Fi / LAN</li><li>TM5 — Multipoint passive observer</li><li>TM6 — Global passive adversary</li><li>TM7 — Malicious contact</li><li>TM8 — Harassment / OSINT doxxing</li><li>TM9 — Ordinary legal request</li><li>TM10 — Sophisticated multisource investigation</li><li>TM11 — Locked device</li><li>TM12 — Unlocked device</li><li>TM13 — Spyware / controlled endpoint</li><li>TM14 — Supply-chain compromise</li><li>TM15 — State censorship</li></ol><p>The matrix is qualitative and configuration-dependent. Strong, partial, exposed, weak and unknown are relative assessments, not absolute grades. Unknown is not a negative score.
