# Metodología

Investigación documental independiente, no certificación de seguridad. Las fuentes incluyen especificaciones, código público, auditorías, artículos académicos, avisos, transparencia y documentos judiciales públicos. Se distinguen declaraciones del proveedor, evidencia independiente e inferencias explícitas.

Conclusiones fechadas el **14 de octubre de 2026**, informe **1.0**. No se trasladan automáticamente a otras plataformas, versiones o ajustes. Observaciones pasivas limitadas de DNS/BGP y muestras de manifests no son una auditoría de producción.

**No realizado:** laboratorio comparativo de red, adquisición forense controlada de móviles actuales, inspección completa de APK/IPA ni reproducción bit a bit de binarios distribuidos. No hubo escaneo de puertos ni acceso no autorizado.

Confianza media para propiedades protocolarias bien documentadas y resultados judiciales publicados; baja a media para metadatos de producción, llamadas por versión, binarios, forense móvil y censura. **Desconocido sigue siendo Desconocido.**
