# OPSEC

<p>Protect devices, identities and files before changing the messenger. Use current OS/app versions, a strong lock, controlled backups, hidden notification previews and only your own linked devices. A disappearing message cannot prevent a recipient from copying it.</p><p>Do not reuse aliases, avatars, signatures or cloud accounts. Inspect photo/document metadata, authors, filenames and thumbnails. Consider voice, language and schedules. VPN/Tor move an observer; verify the actual path instead of assuming protection.</p>
