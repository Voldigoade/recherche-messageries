# Ideas equivocadas



## «E2EE significa anónimo».

El secreto del contenido y la identificación son propiedades distintas. Cuenta, IP y horarios pueden seguir observables.

<a href="/recherche-messageries/es/concepts/e2ee/">Cifrado de extremo a extremo — E2EE</a> · <a class="fact-source" href="https://github.com/Voldigoade/recherche-messageries/blob/main/research/rapport-final-messageries.md#L8" aria-label="Fuente: e2ee-anonymous — report.summary">[1]</a> <a class="fact-source" href="https://github.com/Voldigoade/recherche-messageries/blob/main/research/rapport-final-messageries.md#L142" aria-label="Fuente: e2ee-anonymous — report.metadata">[2]</a>


## «El servicio no lee mis mensajes, así que no sabe nada».

Fechas de cuenta, número o conexiones pueden ser útiles sin texto. Distinguir capacidad y entrega establecida.

<a href="/recherche-messageries/es/concepts/metadata/">Metadatos</a> · <a class="fact-source" href="https://github.com/Voldigoade/recherche-messageries/blob/main/research/rapport-final-messageries.md#L142" aria-label="Fuente: no-data — report.metadata">[1]</a> <a class="fact-source" href="https://github.com/Voldigoade/recherche-messageries/blob/main/research/rapport-final-messageries.md#L208" aria-label="Fuente: no-data — report.legal">[2]</a>


## «Con Tor no pueden rastrearme».

Tor reduce ciertas observaciones locales; no copias, identidad de perfil, dispositivos ni correlación global.

<a href="/recherche-messageries/es/concepts/network-anonymity/">Anonimato de red</a> · <a class="fact-source" href="https://github.com/Voldigoade/recherche-messageries/blob/main/research/rapport-final-messageries.md#L108" aria-label="Fuente: tor — report.threats">[1]</a> <a class="fact-source" href="https://github.com/Voldigoade/recherche-messageries/blob/main/research/rapport-final-messageries.md#L397" aria-label="Fuente: tor — report.limits">[2]</a>


## «Descentralizado significa privado».

Nodos, bootstrap, DHT o contactos pueden ver su parte de datos. Hay que identificar operadores reales.

<a href="/recherche-messageries/es/concepts/privacy/">Privacidad y minimización de datos</a> · <a class="fact-source" href="https://github.com/Voldigoade/recherche-messageries/blob/main/research/rapport-final-messageries.md#L85" aria-label="Fuente: decentralised — report.comparison">[1]</a>


## «Código abierto significa seguro».

El código público ayuda a inspeccionar, pero no prueba que el binario instalado corresponda. No se reprodujo ningún binario actual bit a bit aquí.

<a href="/recherche-messageries/es/concepts/security/">Seguridad</a> · <a class="fact-source" href="https://github.com/Voldigoade/recherche-messageries/blob/main/research/rapport-final-messageries.md#L179" aria-label="Fuente: open-source — report.audits">[1]</a> <a class="fact-source" href="https://github.com/Voldigoade/recherche-messageries/blob/main/research/rapport-final-messageries.md#L46" aria-label="Fuente: open-source — report.methodology">[2]</a>


## «Sin número significa anónimo».

Elimina un identificador, no IP, compras, perfiles reutilizados ni hábitos.

<a href="/recherche-messageries/es/concepts/pseudonymity/">Seudonimato</a> · <a class="fact-source" href="https://github.com/Voldigoade/recherche-messageries/blob/main/research/rapport-final-messageries.md#L25" aria-label="Fuente: no-phone — report.definitions">[1]</a> <a class="fact-source" href="https://github.com/Voldigoade/recherche-messageries/blob/main/research/rapport-final-messageries.md#L363" aria-label="Fuente: no-phone — report.opsec">[2]</a>


## «Una VPN hace anónima la mensajería».

Una VPN desplaza visibilidad y confianza. No borra la cuenta ni otros canales de vinculación. Comprobar la ruta real.

<a href="/recherche-messageries/es/concepts/network-anonymity/">Anonimato de red</a> · <a class="fact-source" href="https://github.com/Voldigoade/recherche-messageries/blob/main/research/rapport-final-messageries.md#L363" aria-label="Fuente: vpn — report.opsec">[1]</a> <a class="fact-source" href="https://github.com/Voldigoade/recherche-messageries/blob/main/research/rapport-final-messageries.md#L397" aria-label="Fuente: vpn — report.limits">[2]</a>


## «Mensajes temporales: nada será recuperable».

El contacto puede copiar o fotografiar. Importan notificaciones, bases, copias y versiones; no generalizar una extracción antigua tras correcciones.

<a href="/recherche-messageries/es/concepts/confidentiality/">Confidencialidad</a> · <a class="fact-source" href="https://github.com/Voldigoade/recherche-messageries/blob/main/research/rapport-final-messageries.md#L363" aria-label="Fuente: disappearing — report.opsec">[1]</a> <a class="fact-source" href="https://github.com/Voldigoade/recherche-messageries/blob/main/research/rapport-final-messageries.md#L208" aria-label="Fuente: disappearing — report.legal">[2]</a>


## «P2P es necesariamente más privado».

Menos centralización puede implicar revelar IP al contacto. Las rutas de llamadas y mensajes son distintas.

<a href="/recherche-messageries/es/concepts/network-anonymity/">Anonimato de red</a> · <a class="fact-source" href="https://github.com/Voldigoade/recherche-messageries/blob/main/research/rapport-final-messageries.md#L85" aria-label="Fuente: p2p — report.comparison">[1]</a> <a class="fact-source" href="https://github.com/Voldigoade/recherche-messageries/blob/main/research/rapport-final-messageries.md#L142" aria-label="Fuente: p2p — report.metadata">[2]</a>


## «Una auditoría prueba que toda la aplicación es segura».

Una auditoría está acotada por versión, fecha, componentes y exclusiones. Comprobar correcciones y retests sin ampliar el ámbito.

<a href="/recherche-messageries/es/concepts/security/">Seguridad</a> · <a class="fact-source" href="https://github.com/Voldigoade/recherche-messageries/blob/main/research/rapport-final-messageries.md#L179" aria-label="Fuente: audit — report.audits">[1]</a>


## «Sin el texto, una investigación no aprende nada».

Datos de cuenta, operador, tiendas, ISP, dispositivos y contactos son fuentes distintas. Un caso no se generaliza a todos.
