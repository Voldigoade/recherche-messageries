# Sécurité du projet

Ce dépôt publie une recherche documentaire ; ce n’est ni un audit des produits, ni une certification, ni un outil de test offensif. Il ne reçoit pas de comptes, de clés ou de messages privés.

Pour une erreur de documentation ou une source obsolète, utiliser les issues. Pour une vulnérabilité d’une messagerie, contacter son équipe via son canal officiel de divulgation ; ne pas publier ici de données personnelles ou d’exploit visant des tiers.

Pour une vulnérabilité dans les scripts ou le déploiement de ce dépôt, utiliser **Security → Report a vulnerability** lorsque disponible. Décrire le composant, le scénario et la version sans joindre de secret ni de données de tiers. Les workflows de pull requests ne reçoivent pas les droits de déploiement ; la publication est limitée à `main`.
